پاراستنا تۆمارا ل GitHub

تۆمارێن ئەندامان ب پاسۆردەکێ دهێنە کۆدکرن و ل Repository وەک فایلێ forge-backup.json دهێنە پاراستن. ئەگەر مۆبایل یان براوزەر بهێتە گوهۆڕین، ب ڤی پاسۆردی دشێی هەمیان ڤەگەڕینی. پشتی جارا یەکێ، هەر جارەکا تو بگوهۆڕی دێ ئۆتۆماتیک دووبارە هێتە پاراستن.

ئاگەهداری: ئەگەر پاسۆردی ژبیر بکەی، کەس ناشێت کۆپیێ ڤەکەت. ل جهەکێ ب ئاسایش بنڤیسە. ئەڤ پاسۆرد ژ تۆکنا GitHub جیاوازە.
